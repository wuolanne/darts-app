# Play Store listing draft

## App name

DartsFlow - Checkout Practice

## Short description

Darts checkout practice, timed finish runs and doubles training.

## Full description

DartsFlow - Checkout Practice is a focused mobile practice app for darts players who want better checkout routines without heavy scorekeeping.

Build confidence on real finish numbers, improve your speed under light pressure and train useful doubles with a clean low-input workflow made for board-side use.

Features:

- Quick Checkout Practice for realistic finish decisions
- Checkout Timed Run for range-based personal bests
- Around the Clock modes for singles, doubles, trebles and common doubles
- Full Sector routines for structured doubles and sector work
- Compact checkout route hints and follow-ups
- Local session history and simple personal best tracking
- English and Finnish language options
- No login required
- Local-only data stored on your device

DartsFlow is not a full X01 scorer, not an online darts platform and not a cloud-based training service. It is a practice-first app for checkout learning, timed finish runs and low-input board-side drills.

## Finnish listing draft

### App name

DartsFlow - Checkout Practice

### Short description

Darts-checkoutit, ajastetut treenit ja tuplaharjoittelu.

### Full description

DartsFlow - Checkout Practice on darts-pelaajille tehty harjoitussovellus, joka keskittyy checkoutteihin, ajastettuihin finish-treeneihin ja matalan syötön harjoitteluun.

Sovelluksella voit harjoitella oikeita checkout-päätöksiä, kehittää nopeutta eri pistealueilla ja tehdä hyödyllisiä Around the Clock- sekä tuplaharjoitteita ilman raskasta otteluscoreria.

Ominaisuudet:

- Nopea checkout-harjoitus realistisilla finish-numeroilla
- Checkout Timed Run omien ennätysten treenaamiseen pistealueittain
- Around the Clock -moodit singleille, tuplille, triploille ja yleisille tuplille
- Full Sector -rutiinit sektorien ja tuplien harjoitteluun
- Kompaktit checkout-reittivihjeet ja jatkot
- Paikallinen harjoitushistoria ja yksinkertaiset ennätykset
- Englannin ja suomen kielivaihtoehdot
- Ei kirjautumista
- Data säilyy paikallisesti omalla laitteella

DartsFlow ei ole täysi X01-scoreri, ei online-darts-alusta eikä cloud sync -palvelu. Se on tarkoitettu selkeään checkout-harjoitteluun, ajastettuihin finish-rutiineihin ja nopeaan treeniin taulun vieressä.
